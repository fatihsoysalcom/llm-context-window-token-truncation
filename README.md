# LLM Context Window Token Truncation

This example simulates how Large Language Models (LLMs) process prompts within a limited "context window," a core concept from the accompanying article. It demonstrates a simplified tokenization process and shows how prompts exceeding the maximum token limit are truncated, potentially causing the LLM to ignore crucial information or instructions at the end of a long input.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
